# Notebooks

En la ICPC, cada equipo lleva un documento de referencia, cariñosamente llamado
notebook, a cada competencia. Estos documentos suelen tener implementaciones de
algoritmos, teoremas dificiles de recordar, y listas de números útiles.

Desarrollar el notebook de tu equipo desde cero es una tarea super pesada, por
lo tanto es recomendable empezar con alguno de estos, o usar algunas partes de
cada uno:

- [La pandilla]( https://github.com/francoderico/la-pandilla/ )
- [El vasito]( https://github.com/mhunicken/icpc-team-notebook-el-vasito )
- [El Diego]( https://github.com/vmartinv/eldiego )
- [KACTL]( https://github.com/kth-competitive-programming/kactl )
